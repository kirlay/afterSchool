# 樱花校区放学情况

宁波市四眼碶小学樱花校区电子大屏用的「放学情况」显示程序。

原版（2024 年）是单文件 `over.py`，班级数和放学时间写死在代码里。v2 做了这些改动：

- 班级数可设置（现在一年级 3 个班，共 23 班）；
- 显示时段可设置，到点自动显示，时段外最小化到任务栏；
- 每天定时复位（默认上午 9:00，时间可设置、也可以关闭）；
- 校名可设置（默认「宁波市四眼碶小学樱花校区」）；
- 窗口宽度/高度（像素）、字号（磅）、行距（像素）都可以在设置里改；
- 有标题栏、默认不置顶：窗口仍是普通窗口（任务栏有图标、可最小化），
  但默认把标题栏顶到屏幕外，内容贴屏幕左上角；可拖动并记住位置；
- 窗口一出现光标就在输入框，直接输入班号即可；
- 窗口图标 `xb.ico` 和屏幕 logo `logo.png` 是外置文件，可随时替换；
- 只有快捷键入口：`F9` 设置、`F1` 帮助；
- 打包成 **32 位单文件 exe**，可在门卫的 Windows 7 SP1 32 位机器上运行；
- GitHub Actions 可手动触发构建。

## 界面与操作

| 操作 | 效果 |
|---|---|
| 输入 `101` 回车 | 一1班变红并显示「一1班放学」 |
| 输入 `-101` 回车 | 一1班恢复绿色「未放学」 |
| 输入 `000` 回车 | 确认后所有班级复位为未放学 |
| `F9` | 打开设置（可改） |
| `F1` | 打开帮助 |
| 按住窗口顶部拖动 | 移动窗口，松手后保存位置 |

编号规则：`年级 + 0 + 班号`，如 `101`、`102`；二年级是 `201`、`202`……
输入框支持全角数字（`１０１`）和减号，回车后自动清空并保持焦点。

显示时段内窗口自动出现（普通窗口、任务栏有图标），时段外自动最小化到任务栏，不是消失；
点任务栏上的「放学情况」可随时还原查看。最小化时默认把所有班级复位（可在设置里关）。
默认标题栏在屏幕外，所以最上面能看到的就是班号列表；需要临时露出标题栏时用 `--decorated` 启动。

程序默认**不置顶**：老师点另一个大屏软件，那个软件就会到最前面，放学窗口自动让位，
显示时段内也一样；窗口刚出现时会正常抬到前面一次。

## 快捷键说明

- 默认 `F9` 打开设置，可在设置里改成 `F10`/`F11`/`F12`/`Ctrl+Alt+F9` 等；
- `Fn` **不能**用作快捷键：它由键盘固件/厂商驱动处理，Windows 收不到；
- 快捷键是全局的（`GetAsyncKeyState` 轮询），窗口最小化到任务栏或没有焦点时同样有效；
- 退出程序：`F9` 打开设置 → 点「退出程序」。

如果快捷键被其它软件占用，改 `settings.json` 里的 `hotkey` 或设置界面里换一个即可。

## 设置

设置窗口包含：

| 项目 | 说明 |
|---|---|
| 校名 | 显示在窗口顶部，默认「宁波市四眼碶小学樱花校区」，留空只显示「放学情况」 |
| 窗口宽度 / 高度 | 像素，默认 548×416 |
| 字号 | 班级文字磅值，默认 16；标题自动 +4，提示自动 -4 |
| 行距 | 行与行之间的像素，默认 44 |
| 班级数 | 每个年级 0–12 个班，0 表示没有这个年级 |
| 显示时段 | 开始 / 结束时间（`HH:MM`），结束必须晚于开始，不支持跨零点 |
| 校准间隔 | 10–3600 秒，默认 120；越大越省电，到点仍准时切换 |
| 每日复位 | 每天到设定时间（默认 09:00）自动把所有班级恢复为未放学，可关闭 |
| 设置快捷键 | 打开设置的快捷键 |
| 窗口置顶 | 可选，默认不勾；勾上会一直盖住其它软件（包括另一个大屏软件） |
| 隐藏时自动复位 | 窗口最小化到任务栏时是否把所有班级恢复成未放学 |
| 窗口位置复位 | 把窗口移回屏幕左上角 |

字号调大时，窗口宽度/高度和行距要一起调大，否则文字会挤在一起。

设置保存在 **exe 同目录的 `settings.json`**（该目录不可写时用 `%APPDATA%\AfterSchool\settings.json`）。
更新程序时保留这个文件，设置就不会丢。

```json
{
  "version": 3,
  "school_name": "宁波市四眼碶小学樱花校区",
  "classes": [3, 4, 4, 4, 4, 4],
  "show": {"begin": "14:50", "end": "16:25"},
  "check_interval_seconds": 120,
  "daily_reset": {"enabled": true, "time": "09:00"},
  "layout": {"width": 548, "height": 416, "font_size": 16, "row_spacing": 44},
  "hide_titlebar": false,
  "topmost": false,
  "reset_on_hide": true,
  "hotkey": "F9",
  "window": {"x": 0, "y": 0}
}
```

`window` 存的是**客户区**左上角：默认 `0,0` 表示内容贴屏幕左上角，标题栏和边框在屏幕外，
但窗口仍是普通窗口，任务栏里能看到；窗口位置复位就是回到 `0,0`。

`hide_titlebar` 没有放进设置界面（避免误操作后找不回窗口）；需要把标题栏显示出来排查问题时，
手动改成 `false`，或用命令 `放学情况.exe --decorated`；反过来 `--no-titlebar` 可以强制隐藏。

旧版（`"version": 1`）的 `settings.json` 首次运行会自动升级：恢复标题栏、取消置顶，
班级数、时间和其它设置原样保留。

## 图标与 logo

| 文件 | 用途 | 替换方式 |
|---|---|---|
| `xb.ico` | 窗口 / 任务栏图标 | 覆盖后重启程序 |
| `logo.png` | 屏幕左上角 60×60 logo | 覆盖后重启程序 |

`logo.png` 由 `xb.ico` 生成（开发期一次性操作）：

```bash
python -m pip install pillow
python tools/make_assets.py
```

exe 文件自身的图标在打包时嵌入，换 exe 的显示图标需要重新打包。

## 从源码运行

需要 Python 3.8 及以上（自带 tkinter 即可，不需要 Pillow）：

```bash
python over.py
```

调试参数：

```text
python over.py --settings    启动后直接打开设置
python over.py --show        本次运行不按时间隐藏
python over.py --now 15:00   把当前时间模拟成 15:00
python over.py --decorated   把标题栏显示出来（排查问题用）
python over.py --no-titlebar 强制隐藏标题栏（排查问题用）
```

单元测试：

```bash
python -m unittest discover -s tests -v
```

## 打包（32 位，兼容 Win7）

门卫电脑是 Windows 7 32 位。64 位 exe 在 32 位系统上不能运行；另外 Python 3.9 起不再支持 Win7。
所以 Win7 版用 **32 位 Python 3.8.10 + PyInstaller 5.13.2** 打包，一个包同时兼容 32/64 位 Win7 和 Win10/11。

```powershell
powershell -ExecutionPolicy Bypass -File .\build_x86.ps1
```

- 第一次运行会自动下载并静默安装 Python 3.8.10（32 位，仅当前用户，不需要管理员权限）；
- 自动创建 `.venv38-win7`，安装依赖、跑单元测试、打包；
- 产物：`dist\放学情况.exe`（单文件）+ 同目录的 `xb.ico`、`logo.png`、`部署说明.txt`；
- 脚本最后会校验 exe 是 32 位（PE machine = 0x014C），不是就报错。

已有 32 位 Python 3.8 的话可以指定目录：`-PythonDir "D:\Python38-32"`。

> 注意：`build_x86.ps1` 需要保存成 **UTF-8 with BOM** 编码（Windows PowerShell 5.1 才能正确读中文）。
> 用 VS Code 编辑后，右下角编码选 "UTF-8 with BOM" 再保存。

## 部署到门卫电脑

1. 把 `放学情况.exe`、`xb.ico`、`logo.png`、`部署说明.txt` 复制到同一个文件夹（例如 `D:\放学\`）；
2. 双击 `放学情况.exe`（第一次会生成 `settings.json`）；
3. 需要「设置」快捷方式时，新建快捷方式指向：
   `"D:\放学\放学情况.exe" --settings`
4. 升级时只替换 exe，保留 `settings.json`。

### Windows 7 注意

- 需要 **Win7 SP1**；
- 如果提示缺少 `api-ms-win-crt-runtime-l1-1-0.dll`，安装 KB2999226 或 `vc_redist.x86.exe`（微软官网可下载）；
- 单文件 exe 每次启动都要解压到 `%TEMP%`，老机器可能要等几秒；
  如果弹出 `INTERNAL ERROR: cannot create temporary directory!`，说明目标机临时目录不可用（见常见问题）；
- 程序是普通窗口，任务栏里能看到「放学情况」；时段外会最小化到任务栏，点它可还原；
- 重复启动会提示「已经在运行」，不会开出第二个窗口。

## GitHub Actions 构建

workflow 改为**手动触发**（push 代码不会自动打包）：

1. 仓库 → **Actions** → `build-win7-x86` → **Run workflow**；
2. 用 32 位 Python 3.8 安装依赖、跑单元测试、打包并校验 32 位；
3. 上传 `after-school-win7-x86.zip`（单文件 exe + xb.ico + logo.png + 部署说明，保留 90 天）。

## 常见问题

**窗口到点没有出现？**
检查 `settings.json` 的 `show` 时间，以及系统时间是否正确；按 `F1` 看帮助确认程序在运行。

**按快捷键没反应？**
可能是被其它软件占用（例如输入法、截图工具）。在设置里换一个组合，或改 `settings.json` 的 `hotkey`。

**设置保存失败？**
检查 exe 所在目录是否可写；不可写时会自动改用 `%APPDATA%\AfterSchool\`。

**设置文件坏了？**
程序会自动改名为 `settings.json.bak-时间戳` 并恢复默认设置，同时提示一次。

**程序出错了？**
看程序同目录的 `error.log`（带时间戳和堆栈）。

**双击 exe 弹“INTERNAL ERROR: cannot create temporary directory!”？**
单文件 exe 启动时要先把自身解压到系统临时目录，失败会弹这个（发生在程序运行之前，跟设置无关）。处理：
1. `Win+R` 输入 `%TEMP%`，确认能打开、能新建文件，检查磁盘空间；
2. 临时应急：写一个 `启动.bat`，先把 `TEMP`/`TMP` 指到程序目录下的 `temp` 文件夹再启动 exe。

**想双开？**
不允许：第二次启动会提示「已经在运行」。
